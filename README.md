# midterm

ამ დავალებაში შესრულებულია პირველი ოთხი კვირის თეორიული ნაწილის ლაბორატორიულების შეჯამება:

შესრულებულია AES-128-CBC უტილიტით ტექსტური ფაილის (secret.txt) OpenSSL-ის საშუალებით დაშიფვრა, ხოლო შემდეგ კი საწყისი ტექსტის აღდგენა.

ნაჩვენებია prime256v1 Elliptic curve მრუდის საფუძველზე გენერირებული ხელმოწერა ფაილზე და შემდეგ რამდენად სწორედ და ხელუხლებლადაა ეს ფაილი განშიფრული.

ნაჩვენებია SHA-256 ალგორითმისა და HMAC-ის გამოყენებით რამდენად დიდი ინტენსივობით იცვლება ჰეში ფაილში თუნდაც ერთი სიმბოლოს ცვლილებით (ავალანჩეს ეფექტი)

პრაქტიკულ მაგალითზე ნაჩვენებია ალისას და ბობის მიერ Private და Public და ასევე Shared Secret გასაღებების გენერაცია და Diffie-Hellman Key Exchange მეთოდით ამ გასაღებების გაცვლა შემდგომი დაშიფრული უსაფრთხო კავშირის უზრუნველსაყოფად.
